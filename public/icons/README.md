# Language and technology icons

SVGs are copied unchanged from Devicon v2.16.0:
https://github.com/devicons/devicon/tree/v2.16.0/icons

Each local `<name>.svg` comes from `icons/<name>/<name>-original.svg`.
The accompanying MIT license is preserved in `LICENSE-devicon.txt`.
The Figma, Vite, Thymeleaf, MongoDB, Supabase, VS Code, IntelliJ, GitHub,
Node.js and Maven icons use the same paths from Devicon v2.17.0.
Brand names and logos belong to their respective owners; inclusion does not
imply endorsement. These files are served locally, without a runtime CDN or API.

The allowlist and aliases live in `src/data/languageIcons.js`. Unknown names
and failed image requests use the existing Lucide Code2 icon instead.
