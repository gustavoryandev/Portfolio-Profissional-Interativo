# Catálogo de projetos

Revisão realizada em 4 de novembro de 2026 pelo plugin GitHub conectado.
Foram consultados os 13 repositórios públicos encontrados no perfil
`gustavoryandev` e o projeto colaborativo `warlleyz/SnakePy`.
O repositório `gustavoryandev/gustavoryandev` contém o README do perfil e foi
incluído como projeto de apresentação pessoal. O catálogo mantém o portfólio
conversacional atual e inclui 14 projetos analisados no GitHub, totalizando
15 entradas.

As descrições e tecnologias ficam em `src/data/perfil.json`, com conteúdo
em português e inglês. A seção Projetos e o card da Astra leem esse mesmo
catálogo, sem limitar a exibição aos quatro primeiros itens. A importação é
um retrato desta revisão; não foi criada sincronização automática.

As quatro prévias remotas usam imagens existentes nos repositórios da Pokédex,
SecureLoginPUC, Portfólio Terminal e Mini Comércio Digital. O componente mantém
o estado de prévia indisponível para projetos sem imagem ou em caso de falha.
A imagem local `public/github.png` representa o perfil GitHub e os projetos
de terminal Carrinho de Compras, Bro Fit e Oficina. GEOSOLAR usa a imagem
local `public/geosolar-login.png`.

O remoto Git do checkout atual aponta para
`gustavoryan-del/Portfolio-Profissional-Interativo`, que retornou 404 na conexão
disponível. A entrada do portfólio conversacional mantém uma ação para abrir
a própria aplicação (`/`), sem atribuir seu código ao repositório do portfólio
terminal nem publicar um link de código não verificado.
